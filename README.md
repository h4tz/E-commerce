# E-Commerce Platform

A full-stack ecommerce platform built with Django and React.

This project was initially inspired by the JustDjango ecommerce tutorial project and has since been progressively customized, modernized, and extended with improved backend architecture, Docker support, and deployment workflows.

## Current Improvements

- Dockerized Django backend
- Frontend/backend separation
- Legacy dependency fixes
- SQLite development setup
- Modern local development workflow

## Planned Improvements

- PostgreSQL support
- Redis caching
- JWT authentication
- CI/CD pipelines
- Production deployment
- Background task processing
- Performance optimizations

## Tech Stack

Backend:
- Django
- Django REST Framework
- SQLite
- Docker

Frontend:
- React
- Redux
- Axios
